# EcoKit - Design System Assets

This directory contains shared design assets used across the Open Climate Transparency Platform.

## Contents

- **Logos**: Brand logos and variations
- **Icons**: Icon set for the platform
- **Wordmarks**: Text-based brand assets
- **Favicons**: Site favicons
- **Design Tokens**: Colors, typography, spacing (future)

## Usage

### In Web Application (`web/`)

```typescript
import logo from '../../EcoKit/logo.png';
```

### In Documentation (`docs/`)

```markdown
![Logo](../../EcoKit/logo.png)
```

## Structure

```
EcoKit/
├── logo.png
├── wordmark.png
├── favicon.png
└── [other assets]
```

## Guidelines

- Keep assets optimized for web use
- Maintain consistent naming conventions
- Document asset usage in design system docs
- Version control all assets

---

**Note**: Design system documentation is hosted at `docs.open-eco.org/design-system`
